# Rallycross: status against the handoff spec

Each line of the spec is marked **Done**, **Partial** (built in a simpler form) or **Not done**.
Circuit benchmark numbers are filled in from `--view=bench --rx` runs (3 laps, solo and with a grid).

## 1. Execution order

| Item | Status | Notes |
| --- | --- | --- |
| 12 circuits from the FIA baseline and sector blueprints | Partial | All 12 are generated by `rx_builder.gd` from per-circuit data in `scripts/data/rallycross.gd`. Layouts follow the sector briefs in outline, not metre for metre. |
| Surface physics and wear | Partial | See section 6 below. |
| Modular props and animations | Partial | See section 5 below. |
| AI and tactical spotter | Partial | See section 7 below. |
| Car audit and replication | Not done yet | Tracked as its own task: `docs/car-audit.md`. |

## 2. FIA baseline

| Parameter | Status | Notes |
| --- | --- | --- |
| Circuit length 800–1,400 m | Done | Each circuit is scaled to its target length. |
| Start grid width 15–18 m | Done | Grid is laid out 5–6 abreast on a 15–18 m start. |
| Track width 12–16 m, wider at T1/bowls | Done | Width keyframes per circuit, 16–25 m in bowls. |
| Joker lane width 10–12 m | Done | `w` is 10–11 m, narrower than the main road. |
| Width transition max 1:20 | Partial | Widths are smoothed, but the 1:20 limit is not enforced by a check. |
| Start line to turn 1 of 100–220 m | Partial | Set by layout; not measured per circuit. |
| Camber 1.5–3 %, bowls 8–18 % | Partial | Banking keyframes and downhill pull exist in physics. A crown on straights is not modelled. |
| Joker delta +1.5 to +2.5 s | Done for Chalk Valley, others pending | AI pace on the lane follows each circuit's `delta`. Chalk Valley measures +1.9 s. |
| Max racers 5 or 6 | Done | Opponent count is capped per circuit. |
